# Учебный маршрут production RAG

- **Идентификатор**: `production-rag-learning-path`
- **Статус описания**: частично подтверждено
- **Последняя проверка**: `2026-08-04`
- **Bead**: `ops-h53.2`

## Назначение

Возможность задаёт существующий учебный маршрут по production RAG для читателя,
который последовательно проходит четыре отслеживаемых Git notebook: от
подготовки фрагментов документа до генерации ответа и оценки RAG-пайплайна.

## Наблюдаемое поведение

В репозитории существует следующая последовательность учебных материалов:

1. `01_chunking_strategies.ipynb` знакомит со стратегиями chunking.
2. `02_embeddings_and_vector_stores.ipynb` продолжает маршрут embeddings,
   метриками сходства и vector stores.
3. `03_retrieval_and_reranking.ipynb` продолжает маршрут retrieval,
   hybrid search, reranking и оценкой retrieval.
4. `04_generation_and_evaluation.ipynb` завершает описанную последовательность
   generation и оценкой RAG.

Этот порядок подтверждён именами файлов, заголовками notebook и явными
переходами между модулями в markdown-заголовках. Он описывает порядок
материалов, но не подтверждает успешное выполнение ячеек или готовность
production-сервиса.

## Входные условия

- Читатель начинает с первого notebook и использует результаты предыдущего
  материала как учебный контекст для следующего.
- Для просмотра требуется среда, способная открыть Jupyter notebook.
- Зависимости, внешние API, datasets и runtime-конфигурация в рамках этой
  проверки не устанавливались и не проверялись.

## Сценарии

### Сценарий: пройти маршрут в заданном порядке

1. **Дано**: четыре notebook присутствуют среди отслеживаемых Git файлов.
2. **Когда**: читатель открывает их по числовому префиксу от `01` до `04`.
3. **Тогда**: он получает последовательность chunking → embeddings/vector
   stores → retrieval/reranking → generation/evaluation.

### Сценарий: определить границу готовности

1. **Дано**: `README.md` перечисляет Module 10 и помечает Modules 09–10 как
   `in progress`.
2. **Когда**: читатель оценивает статус маршрута по текущему репозиторию.
3. **Тогда**: он видит существующие учебные материалы, но не получает обещания,
   что Module 10 завершён или что notebook воспроизводимо выполнены.
